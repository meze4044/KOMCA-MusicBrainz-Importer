# KOMCA to MusicBrainz Work Importer

Open KOMCA's [Korean](https://www.komca.or.kr/srch2/srch_01.jsp), [English](https://www.komca.or.kr/foreign2/eng/S01.jsp), or [Japanese](https://www.komca.or.kr/foreign2/jap/S01.jsp) work search page, then navigate to the intended result.
Each recognized entry gets an **Import into MB** button.

Review the lyricist/composer list, then click the button to open a MB work draft.
KOMCA annotates writers as both lyricist and composer; but this script does not seed writer relationships.
Arrangers and publishers are also not seeded.

KOMCA IDs are linked to MusicBrainz annotation search for quick lookup.

Always check your original source, such as physical media or DSP, for artist credits.
For example, KOMCA often lists each member of a group even when the group is credited.

A single KOMCA ID may map to multiple MusicBrainz entities.
